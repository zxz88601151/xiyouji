1账号同步 (代注册)

本平台的用户主键 external_id 映射到后台账号。同一 ID 重复调用只会返回现状, 不会造第二个号。

2查询状态

本平台要判断"这人能不能用某个功能", 只看 state + remaining, 不自己算到期时间。

3购买会员 (权益同步)

模拟支付成功后, 把订阅折算成秒调 users/extend。订单带 request_id, 重复提交不会加两次时长。注意 extend 只加时长, 不改套餐名 (套餐名来自本站下单)。

4登录

走 auth/login, 与客户端登录是同一条核心路径 (限流、换绑扣时、审计一致)。机器码变了会扣 6 小时。

5令牌校验

auth/verify 问"这人是谁、还有多久"; 下面第二颗按钮把同一个 token 直接打到客户端接口 /api/auth/me, 证明是同一套登录。
